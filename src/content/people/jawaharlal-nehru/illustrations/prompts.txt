ILLUSTRATIONS NEEDED: Jawaharlal Nehru
------------------------------------------------------------------------------
How to use this file
  1. Copy one PROMPT into your image generator.
  2. Save the result with its FILE NAME, in this same folder.
  3. Send it to Claude, who places and reviews the art before publication.
     After an owner-provided image is checked, run: node scripts/place-illustrations.mjs

Only proposed stories without a suitable exact archival scene are listed.
The other angles have real free-use photographs or can use an honest date card.
No prompt is a claim that the pictured detail is documented. Paintings on the
site receive an AI-generated label automatically; NEVER remove that label.
Use the file NAME EXACTLY, matching each proposed story slug. All are 16:6.
